Portofolio Hidayat Eka Saputra

Website portofolio pribadi (CV Dinamis) yang dibangun untuk memenuhi Tugas UTS Pemrograman Web. Website ini memiliki antarmuka modern bergaya *Editorial Minimalist* dengan sentuhan interaktif.

Fitur Utama
- **Halaman Publik:** Menampilkan Hero, About, Experience, Projects (Zig-Zag), Skills (Bento Grid), dan Contact.
- **Dasbor Admin (CRUD):** Halaman rahasia untuk mengelola data Proyek dan Keahlian (Skills) secara dinamis.
- **Sistem Autentikasi:** Login admin sederhana sebelum mengakses dasbor.
- **UI/UX Interaktif:** Custom cursor, animasi lanyard, typing effect, dan transisi warna yang mulus.

Teknologi yang Digunakan
- **Backend:** Python 3, Flask
- **Database:** SQLite, Flask-SQLAlchemy
- **Frontend:** HTML5, Tailwind CSS (CDN), Vanilla JavaScript
- **Fonts:** Anton, Inter, Space Mono (Google Fonts)
